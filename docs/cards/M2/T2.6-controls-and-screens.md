# T2.6 Controls and screens (W, worktree `w`, ≈ 3 AD)

**Inputs:** research 03 §4.26 (the browser game's bindings), PLAN §6.1 M2 "Controls and screens" [S13], `Backroads.Core.DriveInput` / `PlayerVehicle`, `QualityPreset` (Core), the M1 Esc menu and Credits (`Client.UI`: `QuickMenu`, `CreditsPanel`, `PlaytestChecklist`).

**Steps**
1. `Game\Assets\Content\core\bindings.json`: one table for keyboard and gamepad, frozen as a contract (draft ADR-004). Keep the browser game's bindings (W/S/A/D, Space handbrake, E get in/out, L lights, H horn, C camera, R reset upright, X low range, G winch, Q/Z blade, M map, F1 help, F2 graphics, [ ] time) and add: tap I ignition, hold I starter; Left Shift / Left Ctrl gear up / down; hold V clutch; F4 manual/auto (used from M4); K diff lock (M7); Esc menu; F3 debug; F10 checklist. Every action has a gamepad binding (Start menu, hold Start reset upright, D-pad up/down gear, D-pad left ignition, hold = starter). Deadzone 0.14.
2. Input System actions (Driving, OnFoot and UI maps) generated from or checked against `bindings.json`; a driver that fills `DriveInput` (levels and press counters) for `PlayerVehicle.Current` every frame.
3. The Esc menu replaces the M1 stand-in: Resume / Controls / Settings / Credits / Quit (keep the Credits panel and the scene entries for Millbrook and the Engine Bench). F1 controls overlay from `bindings.json`.
4. `settings.json` in `persistentDataPath` with a version field: quality tier (apply through `QualityPreset`), volumes, resolution, bindings; an unknown version falls back to defaults with a message.

**Done when:** EditMode `Input.NoDuplicateBindings` (fails on any key or button bound twice within one action map), `Settings.RoundTrip` (settings survive a restart; an unknown version falls back to defaults with a message).

**Gate:** M2 headline (both tests).
