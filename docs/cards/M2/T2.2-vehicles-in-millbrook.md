# T2.2 Four vehicles in Millbrook (V, worktree `v`, ≈ 3 AD)

**Inputs:** T2.1; the Millbrook scene and CanonRuntime (lane W, M1); today's vehicle models from the oracle (`assets/models/*.glb` via `git show`/`archive`, imported with glTFast; lane A's FBX path arrives with T2.9); `Backroads.Core.IDrivenVehicle` / `PlayerVehicle`.

**Steps**
1. A `VehicleSimSystem` in Millbrook that steps every vehicle at 1/120 s and renders them interpolated.
2. Garage spawn bays at the Millbrook garage (positions from canon); each vehicle settles for 240 steps before it is shown. The truck is the spawn default; switching vehicles happens at the garage (a key or a trigger area; tell lane W the binding you need via the integrator).
3. Each vehicle implements `IDrivenVehicle` (body, hood anchor, velocity, `VehicleHud`, `SetInput(DriveInput)` honouring the press counters); the driven one is `PlayerVehicle.Current`.
4. Lights and horn as in the browser game (L, H).
5. Each vehicle asks `VehicleEngines.Create` for its engine: truck → `v8_bigblock_a`, pickup → `v8_cross_a`, rally → `f4_boxer_a`, hatch → `i4_vvt_a` or `i4_synth` (lane `vs` provides them), and calls `Step` every fixed step with the `EngineState` of `LegacyJsEngine`.

**Done when:** PlayMode `Vehicle.SettleParked` (4 vehicles on the bays settle within 240 steps to |v| < 0.01 m/s); a Dev build starts in the truck at the garage and drives with a scripted `DriveInput` (lane W's real input arrives at merge).

**Gate:** M2 lane (`Vehicle.SettleParked`); "you play".
