# T2.1 BRV V0: the browser game's vehicle model at 1/120 s (V, worktree `v`, ≈ 6 AD)

**Inputs:** oracle `js/vehicle.js` (read with `git -C D:\Backroads show 552f7807:js/vehicle.js`), `CanonData\v1\gameplay\vehicles.json`, `CanonData\v1\reference\traces\*.json` (six golden traces, seeded, no traffic, v1 terrain; recorded in M0), `WorldGridQueries` and `ColliderGrid` (lane W, M1), research 03 §3.6 and §4.14, 06 §3-§5, PLAN §6.1 M2.

**Steps**
1. Port `vehicle.js` verbatim (same equations, same order, same constants) into `Backroads.Vehicles`: suspension rays against `WorldGridQueries`, PGS tyres, `LegacyJsEngine` + automatic gearbox, low range, AWD-on-low, hull contacts, 2D statics against `ColliderGrid`, water, mud grip and sink, winch v0. Keep JS coordinates inside the step and flip at the API (BrCoords), as WorldGrid does.
2. Shape it as `BrvState` + `VehicleStepJob` with snapshot in/out, stepping at exactly 1/120 s (fixed timestep), with render interpolation of the body (03 §4.14 phase 1).
3. Ruts and brush go through `Backroads.Deform.StampSinks.Current` (null = no deformation) with the browser game's arguments; the engine through `Backroads.Core.IVehicleEngine` created by `VehicleEngines.Create(engineId)` (null = silent); BRV must run without the DLL (Architecture rule 3).
4. `ClassicVehicleDef` from `vehicles.json`: hatch, rally, pickup, truck (the dozer waits for M7). Display names: the pickup is the **Kestrel 4x4** (U9); no other renames needed now.
5. PlayMode `Vehicle.GoldenTraces` replays each trace's inputs and compares per-second statistics (03 §3.6), with v1 terrain (no road plates, no road colliders).

**Done when:** `Vehicle.GoldenTraces`: truck 0-80 km/h time ±7 %; pickup 0-100 km/h ±7 %; braking 80 → 0 distance ±8 %; loaded truck low-range quarry climb ±10 %; hatch bog sink depth at 10 s ±15 %; winch 15 m to a tree completes. `Vehicle.SnapshotRoundTrip` < 1 mm. If a trace still misses after tuning, record the delta: the build ships with it and the user judges the feel (U5a).

**Gate:** M2 headline (`Vehicle.GoldenTraces`); lane (`SnapshotRoundTrip`; simulation main-thread time per rendered frame p95 ≤ 3.5 ms at High, ≤ 12 ms on the proxy).
