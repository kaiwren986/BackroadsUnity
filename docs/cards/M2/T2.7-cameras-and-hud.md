**Steps**
1. Chase and hood cameras ported from the browser game (C toggles; mouse look and wheel zoom; right stick), following `PlayerVehicle.Current.Body` / `HoodAnchor`; the fly camera stays available (a debug key) for screenshots.
2. Minimal UI Toolkit HUD: speed, gear (with low range), rpm bar (`VehicleHud.Rpm` / `RedlineRpm`), surface, "sunk N cm", winch state.
3. F3 overlay: frame time, simulation main-thread time, and for the player's engine rpm, torque, MAP, AFR, worker ms, ring fill, underruns, coast events (from the engine-sim stats lane `vs` exposes; leave fields blank until then).
