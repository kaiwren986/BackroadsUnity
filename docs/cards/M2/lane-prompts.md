The prompts the coordinator gave the M2 lane agents on 2026-10-19. Reuse them to restart a lane in a fresh session; each lane keeps `docs\milestones\M2-handoff-<lane>.md` current to resume from.

## Shared by every lane (included in each prompt)

- **Hard rules:** `AGENTS.md`. Never edit `D:\Backroads` (the oracle; read it with `git -C D:\Backroads show 552f7807:<path>`) or `D:\Backroads-ref\engine-sim`; never push, sign in, type passwords or install software; downloads only from the approved list (`docs\approvals\QUEUE.md`). `CanonData\v1` is frozen. No real brand names or logos in anything a Client build shows (shapes are fine). Synty packs are not in lane worktrees.
- **Cards and contracts:** your cards are in `docs\cards\M2\` (read `README.md` there first). The shared contracts on main are `Game\Assets\Backroads\Core\Runtime\VehicleContracts.cs` and `Game\Assets\Backroads\Deform\Runtime\StampSink.cs`: code against them, and never change them on your branch; if one must change, describe it under "For I" and work around it meanwhile.
- **Ownership:** change only paths your lane owns in `OWNERS.json` (longest prefix wins; `X.meta` follows folder `X/`). For a change to anything else (ProjectSettings, `Build\Editor`, `BuildCli`, `ServerMain`, `third-party.json`, `tools\ci\gates.json`, shared test asmdefs, the build scene list, the Core contracts), write it under "For I" in your handoff; if it blocks your own testing, make it on your branch in a separate commit starting `REQUEST FOR I:`.
- **Scenes:** only lane W edits `Millbrook.unity`. Other lanes add things to Millbrook from code when the scene loads (as the Engine Bench builds itself), never by editing the scene file.
- **Tests and autotests:** EditMode/PlayMode/Perf tests in your own asmdef under `Game\Assets\Backroads\Tests\<EditMode|PlayMode|Perf>\<Area>\` (`Backroads.Tests.<Platform>.<Area>`; EditMode ones editor-only). Player autotests implement `Backroads.Testing.IAutotestScenario` in `Game\Assets\Backroads\Testing\Runtime\Scenarios\<Area>\` with a scenario JSON in `Game\Assets\StreamingAssets\Autotest\`.
- **Running Unity and native builds:** only through `tools\ci\*.ps1` (locks, Unity slots, `.user-playing`); see `tools\ci\README.md`. Start PowerShell children with `Start-Process -PassThru` + `WaitForExit()`. Five lanes run in parallel this milestone, so expect to wait for Unity slots and `machine.lock`; do CPU-heavy or perf runs through the scripts only.
- **Writing files:** the Bash tool turns `\\` into `\` inside heredocs; write JSON and scripts containing backslashes with the Write tool and validate JSON with node.
- **Commits:** on your branch only, in logical steps, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Merge `main` into your branch before your final handoff. Keep the handoff current as you go.
- **Report back** (final answer): what you built, each gate of your cards expected vs measured, the "For I" list, deviations, and the branch with its last commit hash. Name 1-3 screenshots worth showing the user (paths), if your work is visible.
