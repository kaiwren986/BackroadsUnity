# M1 lane prompts

The prompts the coordinator gave the M1 lane agents on 2026-10-18. Reuse them to restart a lane in a fresh session; each lane also keeps `docs\milestones\M1-handoff-<lane>.md` current to resume from.

Shared by both lanes (included in each prompt below):

- **Hard rules:** `AGENTS.md`. Never edit `D:\Backroads` (the oracle) or `D:\Backroads-ref\engine-sim`; never push; never sign in; never type passwords; never install software. Downloads only from the approved list (`docs\approvals\QUEUE.md`, U3). `CanonData\v1` is frozen: read it, never rewrite it. No real brands in anything a Client build shows (PLAN §3.10, `Content.NoRealMarks`). Synty packs are not in lane worktrees and M1 does not use them.
- **Ownership:** change only paths your lane owns in `OWNERS.json` (longest prefix wins; `X.meta` follows folder `X/`). `Repo.OwnersRespected` checks it at merge. If you need a change to a file you do not own (ProjectSettings, `Build\Editor`, `BuildCli`, `ServerMain`, `third-party.json`, `tools\ci\gates.json`, the shared test asmdefs, the build scene list), describe the exact change under "For I" in your handoff. If it blocks your own testing, make it on your branch in a separate commit whose message starts with `REQUEST FOR I:`; the integrator reviews those at merge.
- **Tests and autotests:** put EditMode tests in your own editor-only asmdef under `Game\Assets\Backroads\Tests\EditMode\<World|EngineSim>\` (name `Backroads.Tests.EditMode.<Area>`, `includePlatforms: ["Editor"]`, `UNITY_INCLUDE_TESTS`, `nunit.framework.dll`); PlayMode and Perf the same way under `Tests\PlayMode\<Area>\` and `Tests\Perf\<Area>\`. Player autotests are classes implementing `Backroads.Testing.IAutotestScenario` in `Game\Assets\Backroads\Testing\Runtime\Scenarios\<World|EngineSim>\` (see the README there) plus a scenario JSON in `Game\Assets\StreamingAssets\Autotest\`.
- **Running Unity:** use the scripts, so locks and Unity slots are respected: `tools\ci\unity-tests.ps1`, `tools\ci\build-player.ps1`, `tools\ci\autotest.ps1`, `tools\ci\gate.ps1 -Tier merge` (see `tools\ci\README.md`). Never start heavy work while `artifacts\.user-playing` exists. Perf autotests take `machine.lock` themselves. Start PowerShell children with `Start-Process -PassThru` and `$p.WaitForExit()` (`Start-Process -Wait` hangs on the Unity licensing client).
- **Commits:** on your branch only, in logical steps, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Keep the handoff current as you go, so a stop midway loses nothing.
