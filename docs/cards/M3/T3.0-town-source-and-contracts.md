# T3.0 Town source and bake contracts (I, main, ≈ 3 AD)

This replaces the draft `sites-S0-town-source.md`: the integrator does it on main before the lanes start, so every lane
reads the same frozen source.

**Inputs:** ADR-006 (accepted), the overview's contracts 1-5 (`sites-roads-overview.md`), the scout's tools and the
Stockport square (`tools\scout\`, `tools\scout\towns.json`: centre 300 m west and 400 m south of OSM node 154045239),
the site research's classifier (`tools\osm\measure.mjs typeOf`), U23/U25 (the Overpass and 3DEP downloads are approved).

**Steps**
1. `tools\world\fetch-town.mjs`: one Overpass query for the 2 km square + 300 m, and the 3DEP 1 m DEM for the same box
   (ImageServer, raw F32, tiled requests), cached in `artifacts\world-src\stockport-oh\` (gitignored); SHA-256 pins
   and the request URLs go in `sources.json`.
2. `tools\world\extract-town.mjs`: project to the local frame (UTM 17N → metres, x east, z north, origin at the square's
   centre, y = DEM elevation minus `Y0` = lowest river point − 2 m), clip, and write `TownData\stockport-oh\v1\`:
   `roads.json` (ways + nodes with the tags R reads), `buildings.json` (footprints, OSM id, tags, `BusinessType` and form
   from the classifier), `sites.json` (mapped parking, aisles, fuel, yards, barriers, entrances), `landuse.json`,
   `water.json` (river polygon and centreline, dam, lock, creeks), `dem\dem_1m.f32` + `dem.json`, `manifest.json`
   (hashes, OSM timestamp, origin, bbox, tool versions), `credit.txt`.
3. **Strip real names** (ADR-006 §6): drop `name`, `name:*`, `alt_name`, `old_name`, `brand*`, `operator`, `addr:*`,
   `phone`, `website`, `ref` on non-highways; keep `ref` on state roads only as a class hint, never shown. A test fails
   the extract if any dropped key survives.
4. `WorldBakeContracts.cs` in `Backroads.Core` with the types listed in the README, plus draft **ADR-007** (bake
   contracts, field lists, units, the plate order).
5. `OWNERS.json`: lane S and the new paths (README, "Ownership in M3"); `gates.json`: the M3 tier with the steps of
   T3.7 as placeholders; `.gitattributes`: `TownData/**` and `WorldData/**` binaries through LFS, `-text`.
6. Fill the parameters table of `sites-roads-overview.md` for Stockport (`TOWN_ID` stockport-oh, `TOWN_NAME`
   Millbrook, origin, bbox, DEM 1 m, the kerb and downtown zones measured from the extract).
7. Render the extract (the scout's map renderer pointed at `TownData`) as `docs\milestones\M3\town-source.png` and
   show it to the user.

**Done when:** EditMode `Town.ManifestHashes` (every file matches its manifest hash), `Town.NoRealNames`,
`Town.ClassifierFixture` (the C# classifier agrees with `measure.mjs typeOf` on 200 fixture buildings), and
`Town.FrameRoundTrip` (lat/lon → local → lat/lon within 1 mm) pass; the extract re-run from the cache is
byte-identical.
